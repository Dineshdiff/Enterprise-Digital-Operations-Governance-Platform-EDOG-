# Enterprise Digital Operations & Governance Platform (EDOG)

An Enterprise Governance platform built using Microsoft Power Platform.

## Features

- Executive Command Center
- Risk Management
- Compliance Dashboard
- Audit Management
- PMO Governance
- Vendor Management
- AI Command Center
- Strategic Goal Tracking

## Technology Stack

- Power Apps Model Driven Apps
- Dataverse
- Power Automate
- React Custom Pages
- Fluent UI
- JavaScript
- C# Plugins
- Business Rules
- Azure DevOps
- GitHub

## Architecture

50+ Dataverse tables with enterprise governance and compliance framework.
